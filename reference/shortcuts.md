# Atajos de Teclado

Optimiza tu velocidad en el canvas utilizando los atajos de teclado del lienzo de Sketion.

---

## Herramientas de Dibujo
- **V** o **1**: Herramienta de Selección.
- **R** o **2**: Rectángulo.
- **O** o **3**: Elipse.
- **A** o **4**: Flecha.
- **L** o **5**: Línea.
- **P** o **6**: Dibujo manual libre.
- **T** o **7**: Texto.
- **I** o **8**: Imagen.
- **E** o **9**: Borrador.

---

## Acciones de Cámara y Organización
- **Barra Espaciadora + Arrastrar**: Paneo del lienzo.
- **Ctrl / Cmd + Rueda del Mouse**: Acercar y alejar zoom.
- **Ctrl / Cmd + G**: Agrupar elementos seleccionados.
- **Ctrl / Cmd + Shift + G**: Desagrupar elementos.
- **Ctrl / Cmd + Z**: Deshacer última acción.
- **Ctrl / Cmd + Y**: Rehacer acción.
- **Supr / Backspace**: Eliminar elementos seleccionados.
