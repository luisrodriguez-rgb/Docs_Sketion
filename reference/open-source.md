# Atribuciones de Código Abierto

Sketion se construye sobre el trabajo de increíbles proyectos y comunidades de código abierto. Creemos en la transparencia y en el valor de retribuir a la comunidad.

---

Para conocer en detalle el software de terceros utilizado en la plataforma, las licencias y atribuciones correspondientes, visita las siguientes secciones:

- [Dependencias de Código Abierto](/open-source/dependencies): Un desglose completo de las herramientas core (como Excalidraw, Supabase, React) y renderizadores integrados (PDF.js, KaTeX, Mermaid).
- [Licencias y Atribuciones](/open-source/licenses): Términos legales de las licencias MIT y Apache 2.0 que rigen los componentes de software de terceros.
