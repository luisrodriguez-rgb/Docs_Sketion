# Uso de Plantillas

<span class="badge badge-available">✓ Available</span>

Aprende cómo aplicar plantillas preestablecidas a tus pizarras activas.

---

## Aplicar una Plantilla
1. Haz clic en el botón de **Plantillas** en el Dashboard o desde el menú de opciones dentro de una pizarra activa.
2. Navega por las categorías o utiliza la barra de búsqueda para encontrar la plantilla idónea.
3. Haz clic sobre la miniatura de la plantilla.
4. Sketion insertará todo el conjunto de figuras, textos, notas y conectores en tu tablero actual al instante, listos para ser editados.
