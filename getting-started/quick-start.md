# Inicio Rápido

Sigue estos tres pasos simples para comenzar a utilizar Sketion de inmediato.

---

## 1. Abre el Lienzo
Accede a [sketion.vercel.app](https://sketion.vercel.app) y haz clic en **"Abrir App"**. Se creará automáticamente un lienzo infinito local en tu navegador listo para trabajar.

## 2. Dibuja y Escribe
- Selecciona las herramientas de dibujo clásicas en la parte superior central (Rectángulos, Flechas, Círculos) para empezar a estructurar ideas.
- Haz doble clic en cualquier parte del canvas para añadir texto libre.

## 3. Explora la Barra Lateral
En el extremo derecho de tu pantalla verás una columna vertical de iconos. Desde allí podrás activar las funciones premium integradas:
- **Modo Estudio** (Icono de Libro): Para alternar a la previsualización y repaso de flashcards.
- **LaTeX** (Icono de Sigma $\Sigma$): Para insertar expresiones matemáticas.
- **Google Drive** (Icono de Drive): Para importar documentos de la nube.
- **Mermaid** (Icono de Conector): Para traducir código declarativo a diagramas en el canvas.
- **PDF Importer** (Icono de PDF): Para renderizar tus archivos universitarios o de investigación.
