# Filosofía del Producto

Sketion nace para solucionar un problema fundamental en la productividad moderna: el conocimiento no debe estar fragmentado en múltiples herramientas desconectadas.

En lugar del flujo tradicional disperso:
Documento PDF -> Bloc de Notas -> Editor de Código -> Software de Diagramas -> Software de Flashcards

Sketion unifica y conecta todos estos elementos dentro de un único espacio de trabajo visual.

---

## Principios Fundamentales

### Visual-First
El cerebro humano procesa y recuerda la información de forma espacial y visual de manera mucho más eficiente que el texto lineal. Sketion sustituye la estructura jerárquica de carpetas y documentos tradicionales por un lienzo bidimensional infinito donde las relaciones entre ideas son inmediatas y autoexplicativas.

### Local-First
Tu trabajo comienza en tu dispositivo, no en un servidor remoto. Priorizamos la velocidad, la privacidad y la disponibilidad offline de tus pizarras usando bases de datos locales. La nube funciona en segundo plano únicamente como una capa transparente de respaldo y colaboración multiusuario.

### Connected Knowledge (Conocimiento Conectado)
La información aislada pierde valor. Diseñamos Sketion para estructurar grafos de conocimiento a través de conexiones y flechas lógicas que enlazan visualmente secciones de PDFs con fórmulas matemáticas, diagramas y notas.

### Interoperabilidad
No pretendemos crear formatos cerrados. Sketion está construido para trabajar con estándares abiertos (archivos PDF vectoriales, sintaxis estándar de LaTeX, diagramas declarativos de Mermaid y datos estructurados CSV).

### AI-Assisted (Asistido por IA, no dependiente de ella)
La inteligencia artificial en Sketion funciona como un copiloto de productividad enfocado en automatizar tareas mecánicas (como resumir textos o sugerir estructuras de diagramas), dejando el análisis conceptual y las conexiones creativas en manos del usuario.
