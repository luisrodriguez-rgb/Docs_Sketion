# Conexiones

<span class="badge badge-available">✓ Available</span>

Las conexiones son enlaces visuales que unen elementos, permitiéndote estructurar mapas conceptuales y diagramas de flujo interactivos.

---

## Creación de Conexiones
Para vincular dos elementos (por ejemplo, una página de un PDF y una nota flotante):
1. Selecciona la herramienta **Flecha** o **Línea** en la barra superior.
2. Pasa el cursor por encima del primer elemento hasta que veas los puntos de anclaje (bordes resaltados). Haz clic e inicia el trazo.
3. Arrastra el extremo de la línea hasta el segundo elemento hasta que se acople a sus bordes.
4. Suelta el botón. Los dos elementos ahora están vinculados semánticamente.

---

## Comportamiento Dinámico
Una vez creada la conexión:
- **Movimiento Inteligente**: Al desplazar o mover cualquiera de los elementos conectados por el lienzo, la flecha se estirará, encogerá y redirigirá de manera automática para mantener el enlace visual intacto.
- **Tipos de Línea**: Puedes cambiar el estilo de las conexiones a líneas rectas, curvas suavizadas o líneas ortogonales desde el panel de estilos izquierdo.
