# Product Philosophy

Sketion was built to solve a key challenge in modern productivity: knowledge shouldn't be scattered across disconnected tools.

Instead of the traditional fragmented flow:
PDF Document -> Sticky Notes -> Code Editor -> Diagram Software -> Flashcards App

Sketion unifies and connects all these components inside a single visual workspace.

---

## Core Principles

### Visual-First
The human brain processes and remembers spatial and visual layouts much faster than linear text. Sketion replaces hierarchical folders and files with a 2D infinite canvas where conceptual relationships are immediately visible.

### Local-First
Your work starts on your device, not a remote server. We prioritize offline availability, performance, and privacy by leveraging local databases. The cloud operates in the background as a backup and multi-user sync layer.

### Connected Knowledge
Isolated information loses value. We designed Sketion to build knowledge graphs using semantic arrows linking parts of a PDF, mathematical formulas, diagrams, and notes.

### Interoperability
We don't believe in proprietary lock-ins. Sketion is built to work with open standards: vector PDF pages, standard LaTeX math expressions, declarative Mermaid code, and structured CSV tables.

### AI-Assisted (Not AI-dependent)
AI in Sketion is a copilot meant to automate tedious tasks (like summaries or structure suggestions), leaving the critical reasoning, conceptual links, and creative connections in the hands of the user.
